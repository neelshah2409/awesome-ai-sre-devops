# Contributor Code of Conduct

We want this project to be welcoming to everyone. In short:

- Be respectful and assume good faith.
- No harassment, personal attacks, or discriminatory language or jokes.
- Disagree about tools and technical merit, not people.
- Maintainers may edit, close, or remove contributions and comments that don't meet this standard, and may block repeat offenders.

Report unacceptable behavior by opening a confidential issue or emailing the maintainer listed in the repo profile. This adapts the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
